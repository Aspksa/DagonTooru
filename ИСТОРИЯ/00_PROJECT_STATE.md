# Состояние проекта

Автор: Матиенко Антон Александрович · Aspksa@yandex.ru

Версия 0.1.0. Реализовано: локальный Python HTTP API, SQLite, разделение памяти personal/home/work и по проектам, два исходных рабочих проекта, создание проектов, локальный Ollama-адаптер, веб-интерфейс и частичная диагностика. Windows launcher работает при наличии совместимого Python. Запуск и тесты в Linux проверены; Windows вручную не проверялся.

Не реализовано: автоматическое получение portable Python, полноценные AI provider/model manager, интернет/почта, мобильные приложения, публичная многопользовательская версия, очередь, события, резервирование, обновление, безопасный режим и подписанные релизы. См. `04_ROADMAP.md`.
