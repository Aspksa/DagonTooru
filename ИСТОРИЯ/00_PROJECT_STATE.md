# Состояние проекта

Автор: Матиенко Антон Александрович · Aspksa@yandex.ru

Версия 0.1.0. Реализовано: локальный Python HTTP API, SQLite, разделение памяти personal/home/work и по проектам, два исходных рабочих проекта, создание проектов, локальный Ollama-адаптер, веб-интерфейс, частичная диагностика и ручное резервное копирование SQLite во время работы. Адаптер настроен на установленный пользователем Ollama `127.0.0.1:11435` с моделью `tooru-local:4b`. Пользователь подтвердил, что сайт и диалог с AI работают на Windows. Тесты ядра и создание копии проверены в Linux; новый интерфейс копирования на Windows ещё не проверен.

Не реализовано: автоматическое получение portable Python, полноценные AI provider/model manager, интернет/почта, мобильные приложения, публичная многопользовательская версия, очередь, события, полное резервирование и восстановление, обновление, безопасный режим и подписанные релизы. См. `04_ROADMAP.md`.
