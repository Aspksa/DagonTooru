# Состояние проекта

Автор: Матиенко Антон Александрович · Aspksa@yandex.ru

Версия 0.1.0. Реализовано: локальный Python HTTP API, SQLite, разделение памяти personal/home/work и по проектам, два исходных рабочих проекта, создание проектов, локальный Ollama-адаптер, веб-интерфейс и частичная диагностика. Адаптер настроен на установленный пользователем Ollama `127.0.0.1:11435` с моделью `tooru-local:4b`; действительный запрос с компьютера пользователя через сайт ещё не подтверждён. Пользователь сообщил, что сайт открылся на Windows. Запуск и тесты ядра в Linux проверены.

Не реализовано: автоматическое получение portable Python, полноценные AI provider/model manager, интернет/почта, мобильные приложения, публичная многопользовательская версия, очередь, события, резервирование, обновление, безопасный режим и подписанные релизы. См. `04_ROADMAP.md`.
