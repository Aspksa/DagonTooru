# Изменения

Автор: Матиенко Антон Александрович · Aspksa@yandex.ru

## 0.1.0 — первая реализация

Созданы ядро, SQLite, локальный API и веб-интерфейс. Добавлены исходные проекты, изоляция памяти, подключение к уже установленной Ollama, Windows launcher и интеграционные проверки. Исходная спецификация помещена в `docs/`.

Адаптер AI подключён к адресу и модели из журнала установки пользователя. Диагностика отличает доступный сервер от наличия выбранной модели. Добавлены проверки API `/api/tags` и `/api/chat` на локальном тестовом сервере.

Исправлен таймаут длинного ответа: генерация ограничена 256 токенами, задано `think: false`, увеличен запас времени, добавлены явные сообщения о таймауте и статус ожидания в диалоге.

Добавлена кнопка резервной копии базы в настройках. SQLite создаёт согласованный снимок, проверяет целостность и записывает SHA-256.

Добавлен механизм SQLite migrations через `database/migrations/NNN_*.sql` и `PRAGMA user_version`. Первая миграция `001_initial.sql` совместима с уже существующей базой версии 0 и не удаляет данные.

Добавлено восстановление SQLite из локальной папки `backups/` через `POST /api/v1/backups/restore`. Перед заменой базы проверяются SHA-256, `PRAGMA integrity_check` и версия схемы; автоматически создаётся safety-backup текущей базы.

Интеграционный набор расширен до 10 тестов: отдельно проверены миграция старой базы, успешное восстановление и отказ при неверном SHA-256 без повреждения текущих данных.
