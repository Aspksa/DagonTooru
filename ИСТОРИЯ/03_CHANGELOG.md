# Изменения

Автор: Матиенко Антон Александрович · Aspksa@yandex.ru

## 0.1.0 — первая реализация

Созданы ядро, SQLite, локальный API и веб-интерфейс. Добавлены исходные проекты, изоляция памяти, подключение к уже установленной Ollama, Windows launcher и интеграционные проверки. Исходная спецификация помещена в `docs/`.

Адаптер AI подключён к адресу и модели из журнала установки пользователя. Диагностика теперь отличает доступный сервер от наличия выбранной модели. Добавлены проверки API `/api/tags` и `/api/chat` на локальном тестовом сервере.

Исправлен таймаут длинного ответа: ограничена генерация 256 токенами, задано `think: false`, увеличен запас времени, добавлены явные сообщения о таймауте и статус ожидания в диалоге.

Добавлена кнопка резервной копии базы в настройках. SQLite создаёт согласованный снимок, проверяет целостность и записывает SHA-256; интеграционный тест проверяет данные в копии.
