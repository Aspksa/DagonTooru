# Проверки

Автор: Матиенко Антон Александрович · Aspksa@yandex.ru

Команда: `python -m unittest discover -s tests -v`.

Результат: 7 тестов прошли в Linux (2026-09-30). Проверены SQLite и исходные проекты, изоляция контекста памяти при API/AI-запросе, запрет записи из чужого Origin, подключение к локальному тестовому Ollama `/api/tags` и `/api/chat`, лимит ответа 256 токенов, запрет удалённого адреса AI и сообщение о таймауте. Новый тест проверил создание online резервной копии через API, наличие памяти, целостность, SHA-256 и независимость снимка от последующих записей. Модули Python прошли `compileall`. Пользователь подтвердил работу сайта и AI диалога на Windows; новая кнопка резервного копирования там ещё не проверена.
