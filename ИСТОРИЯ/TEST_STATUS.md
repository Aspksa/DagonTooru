# Проверки

Автор: Матиенко Антон Александрович · Aspksa@yandex.ru

Команда: `python -m unittest discover -s tests -v`.

Результат: 10 тестов прошли в Linux (2026-09-30).

Проверены:
- SQLite и два исходных рабочих проекта;
- изоляция контекста памяти при API/AI-запросе;
- запрет записи из чужого Origin;
- локальный тестовый Ollama `/api/tags` и `/api/chat`;
- лимит ответа 256 токенов, запрет удалённого AI и сообщение о таймауте;
- online backup, наличие данных, `PRAGMA integrity_check`, SHA-256 и независимость снимка от последующих записей;
- схема SQLite версии 1;
- миграция существующей базы с `PRAGMA user_version=0` без потери существующей памяти;
- восстановление проверенной копии через API и создание safety-backup;
- отказ восстановления при неверном SHA-256 без изменения текущих данных.

`python -m compileall -q core tests` — успешно.

Пользователь ранее подтвердил работу сайта и AI-диалога на Windows. Новые миграции и restore-механизм на Windows/внешнем SSD пока не проверены.
