# Решения

Автор: Матиенко Антон Александрович · Aspksa@yandex.ru

- На первом этапе Python стандартной библиотеки позволяет запустить ядро без установки пакетов.
- Локальный сервер связывается только с 127.0.0.1; POST требует same-origin и JSON. Публичный доступ потребует отдельной архитектуры аутентификации.
- Контекст памяти выбирается явно; память другого проекта не попадает в запрос к модели.
- Нельзя автоматически скачивать неподтверждённый исполняемый Python. Переносимый runtime подготавливается отдельно до реализации проверяемой установки.
- Текст авторства в исходниках не считается подписью Ed25519.
- По журналу установки пользователя локальная Ollama слушает `127.0.0.1:11435`, модель называется `tooru-local:4b`. Это значения по умолчанию, с возможностью переопределения переменными окружения; адрес ограничен loopback.
- Резервная копия SQLite создаётся online backup API при работающем ядре и проверяется до публикации файла. Она хранится рядом с проектом; пользователь копирует её на другой носитель отдельно.
- Изменения схемы SQLite выполняются только последовательными миграциями `database/migrations/NNN_*.sql`; номер применённой схемы хранится в `PRAGMA user_version`.
- Восстановление разрешено только из локальной папки `backups/` после проверки SHA-256, `PRAGMA integrity_check` и совместимости схемы.
- Перед восстановлением всегда создаётся отдельный safety-backup текущей базы. Если восстановление после замены базы завершается ошибкой, ядро пытается вернуть safety-backup.
- Защита одного экземпляра строится на OS-level файловой блокировке, а не на PID-файле и не на факте занятого TCP-порта. На Windows используется `msvcrt.locking`, на Linux/macOS — `fcntl.flock`.
- Содержимое `runtime_state/core.lock` является диагностикой; даже если после аварии в нём осталось состояние `running`, новый процесс ориентируется на возможность захватить блокировку ОС.
- Launcher определяет работающую Тоору через `/api/v1/system/identity` и service id `dragon-tooru-core`; случайный локальный HTTP-сервис на 8765 не считается ядром.
