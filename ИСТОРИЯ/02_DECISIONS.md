# Решения

Автор: Матиенко Антон Александрович · Aspksa@yandex.ru

- На первом этапе Python стандартной библиотеки позволяет запустить ядро без установки пакетов.
- Локальный сервер связывается только с 127.0.0.1; POST требует same-origin и JSON. Публичный доступ потребует отдельной архитектуры аутентификации.
- Контекст памяти выбирается явно; память другого проекта не попадает в запрос к модели.
- Нельзя автоматически скачивать неподтверждённый исполняемый Python. Переносимый runtime подготовляется отдельно до реализации проверяемой установки.
- Текст авторства в исходниках не считается подписью Ed25519.
- По журналу установки пользователя локальная Ollama слушает `127.0.0.1:11435`, модель называется `tooru-local:4b`. Это значения по умолчанию, с возможностью переопределения переменными окружения; адрес ограничен loopback.
