# Архитектура

Автор: Матиенко Антон Александрович · Aspksa@yandex.ru

`core.server` запускает один локальный HTTP сервер на 127.0.0.1. `core.storage` управляет SQLite в папке репозитория, создаёт таблицы и проверяет принадлежность проекта области перед чтением и записью. `core.ai` вызывает локальный Ollama и получает только записи явно выбранного контекста. `web/static` обращается к API `/api/v1/`. Отдельный процесс AI не является ядром проекта. Данные пользователя, модели и секреты исключены из Git.

Доступ пока рассчитан на одного владельца на одном компьютере. Система не имеет аутентификации и не должна выставляться в сеть.
