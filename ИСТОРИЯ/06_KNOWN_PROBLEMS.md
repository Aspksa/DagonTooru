# Известные ограничения

Автор: Матиенко Антон Александрович · Aspksa@yandex.ru

- Сайт и AI-диалог работают у пользователя на Windows. Новые миграции SQLite и восстановление резервной копии на пользовательской Windows/внешнем SSD ещё не подтверждены.
- Backup/restore сейчас охватывает только SQLite базу. Файлы проектов вне базы, настройки, секреты и другие защищаемые каталоги пока не входят в полный Backup Manager.
- Восстановление реализовано через API, но отдельного безопасного UI восстановления пока нет.
- Если порт 8765 занят другой службой с совместимым ответом status, launcher может открыть её адрес; надёжная проверка экземпляра запланирована.
- Для диалога нужен отдельно установленный и запущенный Ollama с выбранной моделью.
- Авторизация отсутствует; сервер предназначен исключительно для localhost.
