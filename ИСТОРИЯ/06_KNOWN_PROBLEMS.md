# Известные ограничения

Автор: Матиенко Антон Александрович · Aspksa@yandex.ru

- Сайт и AI-диалог ранее подтверждены на Windows. Новая защита одного экземпляра ещё не проверена на пользовательской Windows/внешнем SSD.
- Backup/restore сейчас охватывает только SQLite базу. Файлы проектов вне базы, настройки, секреты и другие защищаемые каталоги пока не входят в полный Backup Manager.
- Восстановление реализовано через API, но отдельного безопасного UI восстановления пока нет.
- `runtime_state/core.lock` может после аварийного завершения содержать старое диагностическое состояние `running`; это не мешает запуску, потому что источником истины является OS-level lock.
- Launcher и ядро используют один `TOORU_PORT`; по умолчанию это 8765. Конфликт выбранного порта с посторонней программой должен завершать запуск ядра, а не принимать чужой сервис за Тоору.
- Для диалога нужен отдельно установленный и запущенный Ollama с выбранной моделью.
- Авторизация отсутствует; сервер предназначен исключительно для localhost.
