# Известные ограничения

Автор: Матиенко Антон Александрович · Aspksa@yandex.ru

- Portable Python installer остаётся IN_PROGRESS до фактической проверки на Windows и внешнем SSD.
- Базовый Crash Recovery реализован и протестирован в Linux, но реальное аварийное завершение/повторный запуск на пользовательской Windows/SSD ещё не подтверждены.
- Crash Recovery сейчас автоматически проверяет SQLite. Safe Mode и Maintenance Mode ещё не реализованы, поэтому при recovery error ядро прекращает обычный запуск, но не предлагает отдельный минимальный режим.
- Backup Manager пока охватывает только SQLite; проекты, пользовательские настройки, память вне БД и другие защищаемые каталоги не входят в полный backup.
- Linux-регрессия на Python 3.13 выдаёт `ResourceWarning` о незакрытых SQLite connection во время существующих backup/restore тестов. Ошибок тестов нет, но lifecycle соединений требует отдельной проверки.
- Для диалога нужен отдельно установленный и запущенный Ollama с выбранной моделью.
- Авторизация отсутствует; сервер предназначен только для localhost.
