# Известные ограничения

Автор: Матиенко Антон Александрович · Aspksa@yandex.ru

- Сайт открылся у пользователя на Windows; сохранение памяти и ответ AI через браузер ещё не подтверждены.
- Если порт 8765 занят другой службой с совместимым ответом status, launcher может открыть её адрес; надёжная проверка экземпляра запланирована.
- Для диалога нужен отдельно установленный и запущенный Ollama с выбранной моделью.
- Первая схема SQLite не имеет механизма миграций. Не меняйте схему существующей базы вручную.
- Авторизация отсутствует; сервер предназначен исключительно для localhost.
