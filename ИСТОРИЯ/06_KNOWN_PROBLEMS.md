# Известные ограничения

Автор: Матиенко Антон Александрович · Aspksa@yandex.ru

- Portable Python installer находится в состоянии IN_PROGRESS до проверки на Windows и внешнем SSD.
- Обновление закреплённой версии Python требует повторной проверки источника и контрольных сумм.
- Backup Manager пока охватывает только SQLite.
- Single-instance protection проверена на Linux, но `msvcrt.locking` и полный сценарий повторного запуска ещё требуют практической проверки на Windows.
- `runtime_state/core.lock` может после аварийного завершения содержать старое диагностическое состояние `running`; это не мешает запуску, потому что источником истины является OS-level lock.
- При конфликте рабочего `TOORU_PORT` ядро должно завершиться до инициализации `Storage`; этот сценарий ещё требует практической Windows-проверки.
- Авторизация отсутствует; сервер предназначен только для localhost.
